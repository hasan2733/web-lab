# web-lab

A small collection of front-end experiments and demos built with HTML and CSS.

## About

This repository contains simple web lab exercises, playground pages, and experiments intended for learning and prototyping. The codebase is focused on HTML and CSS.

## Project structure

- `index.html` — main demo (if present)
- `css/` — stylesheet files
- `assets/` — images, fonts, and other static assets

## Run locally

1. Clone the repository:

```bash
git clone https://github.com/hasan2733/web-lab.git
cd web-lab
```

2. Open `index.html` in your browser, or run a local static server:

```bash
# Python 3
python3 -m http.server 8000
# then open http://localhost:8000
```
